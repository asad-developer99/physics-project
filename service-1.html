Interactive 3D
Physics Simulations

About this feature

How It
Works and What You Can Do

Each simulation is a 3D scene drawn in your browser with Three.js and WebGL. You change a value, such as a force, an area or an angle, and the model responds instantly, so you can connect every formula to what actually happens.

View simulations

Interactive 3D Models

+
-

An interactive 3D model lets you look at a physical system from every side. You can rotate it, zoom in and move around it, so the parts that a flat textbook drawing hides become clear.

Take Pascal's Law as an example. A textbook shows the hydraulic lift from one side only. In 3D you can turn the model and see the liquid inside the sealed chamber, the two pistons and the way the pressure acts on both.

Each model is built from simple shapes and colours so that the important parts, such as forces, fields and paths, stand out and are easy to follow.

In short, 3D models turn abstract ideas into something you can see and explore, which helps you understand and remember them.

Live Parameters

+
-

Every simulation has controls for the values that matter, such as force, area, volume, angle or speed. Change a value and the model responds immediately, so cause and effect are easy to see.

Before each change, ask yourself what will happen, then run it and check. This habit of predicting and testing builds real understanding and is far more powerful than memorizing a formula.

Built-in Theory

+
-

Every simulation comes with matching theory: a short definition, the key formula, a worked example and real-life uses. You first learn the idea, then watch it work, so formulas stop being symbols and start to make sense.

Safe Virtual Experiments

+
-

Real experiments can be costly, risky or simply impossible in a school without enough equipment. Virtual experiments are free, safe and repeatable, so you can run the same one as many times as you like. They show ideal conditions, so they support real labs rather than replace them.

Runs in Any Browser

+
-

The library runs in a normal browser with no installation and no sign-up. It is built with HTML, CSS and JavaScript, and the 3D graphics are drawn with Three.js using WebGL, so it works on any device with a decent browser and graphics support.
