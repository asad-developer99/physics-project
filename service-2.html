Concept Theory
and Formulas

About this feature

Learn the idea,
then watch it work

Every simulation sits beside a short theory section written in simple words. You read the idea, see the formula, follow an example, and then open the 3D model to check that it really behaves that way.

View simulations

Key Definitions

+
-

Each topic starts with a plain-language definition. We explain terms such as pressure, field or wavelength in a sentence or two, so you know exactly what the simulation is showing before you touch it.

Formulas Explained

+
-

A formula is shown with every symbol named and its unit written next to it. For Pascal's Law, for example, you see how force, area and pressure connect.

Then you change those values in the simulation and watch the formula come alive, instead of memorizing it as a string of letters.

Worked Examples

+
-

Each theory section includes a step-by-step example with real numbers. You can follow the working on paper, then enter the same numbers into the simulation and compare the result.

Real-Life Uses

+
-

Physics matters more when you can see where it is used. We link each concept to everyday things, such as car brakes and hydraulic jacks, cameras and lenses, or pressure cookers and gas pistons.

Theory Beside the Model

+
-

Theory and simulation are placed on the same page, so you never have to switch between a textbook and a screen. Read a line, try it in 3D, and read the next line.

How a theory
section is built

Every topic follows the same four-part pattern,
so you always know where to look.

01
Definition

A short, plain explanation of the idea and the terms it uses.
02
Formula

The key equation with each symbol and unit explained.
03
Worked Example

A numerical problem solved step by step that you can repeat in the model.
04
Real-Life Use

Where the same idea shows up in daily life and technology.
